## 核心规则

- 不重新调用模型，不下载题目镜像。原配置、密钥、历史轨迹／预测／评测输入保持原字节。
- 内容预览仅用于审阅，不保证可作为 Git 应用补丁。新快照才能提供精确前后内容；旧记录缺少文本时说明原因。
- 内容快照最多每文件 200 KB、合计 2 MB；差异合计 2 MB。已结束任务按现有存储页可预览后清理；不自动清理旧历史或本轮证据。
- 单条消息最多展示约 4000 字符，原始事件与轨迹未裁剪。历史分页仍需顺序扫描本机文件；本轮不引入数据库或索引迁移。
- 对话分页、设置冲突和缓存检查使用请求代次／版本保护。真正恢复代理上下文仍不提供。
