## 证据与范围

本次证据在 [workbench-fixes 产物目录](../artifacts/2026-09-15/workbench-fixes/)：

- workspace-desktop.png、workspace-narrow.png：实际页面截图，测试配置为隔离样例。
- 16 项 pytest 通过，私有 XML 在 .local/webui/audit/fix-pytest.xml；使用现有 pytest，不安装新依赖。附加检查修复了默认全局调用数固定为 45 与页面高步数设置不一致的问题；用户显式设置的全局限制仍保留并显示。

故障测试只操作独立测试实例；为覆盖 Docker 无法访问时的恢复，使用明确标注的合成孤立资源记录，调用真实 Docker 查询失败路径，没有创建或删除真实容器。它证明应用如何处理这一故障，不证明 Docker 本身已恢复。

文件变化摘要来自前后文件指纹，排除缓存、环境、疑似凭据和大文件，达到数量／时间边界时明确标为不完整。不能据此认定未检查文件未变，也不能区分同时进行的人工修改。Git 差异可能包含同一文件之前已有的改动。
