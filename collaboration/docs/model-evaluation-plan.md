# 多模型配置与一体化评测中心 · 1.4

## 背景与目标

原工作台只能保存一套连接，求解和评测分别打开，难以判断实际解决情况，也无法稳定比较不同模型。此次保持 Windows 本机、中文浅色界面、FastAPI 和原生 JavaScript，复用已有 Python 环境与依赖。

目标：保存多个服务及模型；连贯展示准备、求解、补丁、评测、结果；支持历史结果整理和固定题集的多模型顺序实验。

## 模型与凭据

- 服务连接保存地址与独立 DPAPI 加密凭据，模型档案保存连接引用、真实模型 ID、Chat/Responses 协议、参数、价格和限额。官方模板只辅助填地址，不保证具体模型可用。
- 原配置档案始终读取原 `.env`、`windows.yaml` 和 DPAPI 文件。网页默认档案独立保存，不随切换覆盖命令行配置。
- 保存配置不请求模型。获取模型目录需用户主动点击。工具测试需预览确认，最多两次请求、每次最多 256 输出 token，不重试、不执行工具命令；估算费用阈值 $0.05 并非账单硬限额。
- 价格统一 USD/百万 token。自定义优先，内置价格注明来源，免费明确指定；无 usage 或不能计价保持未知，阻止后续模型调用。
- 所有有效参数、模板、工具格式、限制、价格冻结进任务快照；密钥只保存引用和版本。模型协议/参数不兼容时明确失败，不静默丢参。运行中不热换密钥。

## 调度与首轮规则

- 新网页 SWE-bench 求解默认自动评测，可关闭；旧 API 省略选项时保留旧行为。只评测本次成功的非空提交。
- 实验最多五模型、模型数乘题数最多五十；题目优先、模型次序串行。统一步数、单题费用与超时，另确认实验总预算。总预算默认单题上限，不自动放大。
- 每次新求解独立容器、相同 base commit；不共享其他模型的对话或补丁。数据下载、镜像下载、自动执行命令分别授权。
- 复用唯一队列和执行槽，一个未结束批次；异常暂停，普通未通过继续。关闭网页继续运行，退出后台停止派发，重启不自动恢复。
- 求解重试形成新的 attempt，不覆盖首轮；同一补丁的评测重试保留求解身份与每次评测记录。重复请求编号不得重复创建或调用。
- 无关档案编辑不影响实验；仅凭据变化可重新确认继续；执行条件变化需新建实验版本。

## 指标和来源

- 单题首要结论是官方 resolved；分别展示 FAIL_TO_PASS 修复测试与 PASS_TO_PASS 回归测试。20/21 通过仍可能未解决。
- 历史按配置、数据集、题目去重，取最近有效评测；展示后续异常、缺测与覆盖率。此比例不代表全集成绩或 pass@1。
- 实验主成绩是首轮已解决题数/固定目标题数；取消、异常、未评测单独标识。重试结果另列。
- 同题对比矩阵、解决率条形、费用与耗时表同时呈现；历史比较注明共同题集与排除原因，无共同题不排名。
- 结果关联使用 attempt_id、solve_run_id、evaluation_run_id 和补丁哈希；旧 parent_id 仅为复制来源。旧数据只可靠匹配，歧义标未知，不改原历史。
- 未知成本/时间不能填零或补造。CSV/JSON 导出不含密钥、原对话、原提示词；独立诊断数据不计正式成绩。

## 接口与存储

- `/api/connections` 和独立 `/key`、`/models`；`/api/profiles`、`/default`、`/{id}/test/preview`、`/{id}/test`。
- `/api/experiments`、`/preview`、`/{id}`、`/{id}/control` 复用队列；`/api/results`、`/compare`、`/export`、`/{attempt_id}` 只读聚合。
- 任务/队列支持可选 profile_id；单题支持 auto_evaluate，返回 workflow_id；任务详情同时返回 workflow 与 result_summary。
- 私有档案在 `.local/webui/profiles/`，实验继续使用 queues，子任务继续使用 runs。原缓存、轨迹和正式评测路径不迁移。
- 方案和操作说明留在 collaboration/docs，脱敏验收资料在 collaboration/artifacts/日期/主题；原始日志和隔离实例在 .local/webui。

## 验收与发布

已有 43 项测试作为基线。新增隔离测试覆盖：密钥隔离、同名不同价、计价未知、参数冻结、协议工具往返、三模型顺序、预算、暂停恢复、首轮不覆盖、补丁关联、历史去重、95.2% 未解决、无共同题集、导出脱敏和鉴权。浏览器检查桌面与 390px 窗口。

真实历史可只读验证指标；真实付费模型测试和新大镜像下载未包含在本轮授权。正式后台重启需另确认；不接管用户浏览器。实际通过项和未验证边界以 current-state.md 为准。
