## 已实施规则

| 范围 | 修复与预期行为 |
| --- | --- |
| Docker 超时 | 宿主 docker exec 超时即停止求解和后续模型调用，再由所属资源清理流程确认容器移除；不能把仍可能运行的命令作为普通测试失败继续 |
| 最终状态写盘 | Windows 持续占用等错误保留独立恢复记录，始终释放执行槽；显示“重试状态恢复与资源清理” |
| 费用完整性 | 任务事件写入失败可能丢失用量时标为未知，阻止后续付费求解，不能用残存估算当完整费用 |
| 清理后恢复 | 批次保留当前子任务关联；清理成功后继续消费原结果和本次补丁，不要求重新付费求解 |
| 损坏队列 | 完整校验队列和嵌套条目；损坏记录保留并隔离，设置和历史仍可使用，派发保持阻止 |
| 多未结束批次 | 结束多余批次后重新计算阻塞；即使派发被阻止，也能接收已经清理完成的子任务结果 |
| 退出竞态 | 取消退出与后台进入退出阶段共用同一锁，不能同时向用户确认两种相反结果 |
| CSV 导出 | 参数条件先递归脱敏再序列化，嵌套字段不会绕过脱敏 |
| 补丁来源 | 明确指定的求解来源缺失时，不以相同补丁或模型猜测另一个任务；已知尝试或服务条件冲突也不关联 |
| 独立评测 | 无可靠来源的评测按来源、执行配置、补丁区分；无法可靠去重时保留独立记录 |
| 首轮成绩 | 未结束批次和实验首轮相关任务受清理保护，包括首轮补丁的后续重评；重试记录仍可清理，既有缺失记录保持未知 |
| 预览授权 | 表单改动使旧预览失效；迟到响应不能恢复旧预算或下载授权，提交前再次对照表单快照 |
| 实验切换 | 读取、轮询和控制均绑定实验 ID 与请求版本；旧实验响应不能覆盖新选择 |
| 比较与分页 | 返回空选择的历史比较仍可选模型；临时防重复点击不再撤销业务禁用，例如历史末页下一页 |
| 参数一致性 | Responses 验证和求解共用参数转换，推理强度发送为 reasoning.effort；Chat 明确设置的推理参数由实际中转接口校验，内部别名白名单不预先拒绝 |
| 验证断线 | 先查询原请求；缺失记录需明确“结束本次等待”，写入关闭记录拦截迟到提交并使旧预览失效；新验证需重新预览和费用授权 |
| 验证保存失败 | 内存保留终态并释放执行槽，查询仅重试保存；后台退出后仍无法确认的旧记录显示未完成，不重新调用模型 |
