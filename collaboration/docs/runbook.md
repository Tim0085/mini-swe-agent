# Mini 工作台操作说明

## 1.6.1 Pro 流程修复

正式后台已于 2026-10-10 获准切换到 1.6.1；以下变化已生效：

- 从单题下拉选中已缓存 Pro 题目后可直接开始；缓存损坏会显示具体原因及重新缓存指引。
- 切任务、取消补评或收起详情后，迟到响应不会重新打开旧确认框。网络中断后的原请求核对仍保留，避免重复提交。
- Pro 等待人工批准也受本题总时限约束；到期不执行未批准命令，保存已有改动并使旧批准失效。非 Pro 的人工等待方式不变。
- 求解失败但留下补丁时，结果仍显示失败，并另提供明确的手动评测入口；费用未知不会显示成免费。
- 结果和模型比较区分档案预算与本次实际预算；历史没有足够执行记录时显示未知。实验仍一模型一列，预算因题目不同而变化时会提示。
- Pro 公共题目资料约 2.75 MB，只需按固定版本缓存一次；不同新题复用，不逐题重复读取整份源数据。旧完整单题仍能离线使用。

修复及验收详情见 [10 项修复说明](pro-workflow-fixes-2026-10-10.md)。

## SWE-bench Pro V2（1.6）

在实例库的“题集”中选择 **SWE-bench Pro V2（公开题集）**，再搜索题意或仓库并勾选题目。完整题号自动带入，不需要手填。当前是固定 642 题公开版本；每页默认仍为 8 条，新建任务、实验与评测中心也能选择同一题集。

首次使用点击“同步题目目录”，只保存公开题目资料。单题“缓存题目”还会核对官方说明和评测资源；显示缓存不完整时，明确允许资料下载并重新缓存。镜像下载仍独立授权，已有镜像复用。

求解在断网容器中进行，模型连接保留在宿主，官方隐藏测试只交给后续新建的评测容器。模型正常结束时保存真实代码改动；达到步数、费用或可确认的总时间限制时，非空改动标为“部分补丁”，保留实际停止原因。勾选自动评测可继续评测该份补丁。模型接口费用未知、Docker 故障等执行异常仍暂停；主动停止不会触发评测。

结果页显示官方“已解决／未解决”与修复、回归测试计数。比较前先选定 Pro 题集，不混算不同基准成绩。少量自选题与当前 $3、40 步限制不能代表完整官方榜单。采用 1 CPU、4096 MiB 与最多 50 分钟求解限制；Docker Desktop 不强制官方 10 GB 可写层配额，实际耗时也受本机影响。目录缓存和官方资源放在工作台私有目录，镜像空间由 Docker 管理。

已完成 gpt-5.6-luna 的同题真实求解及官方评测：修复 1/1、回归 9/9，9 次调用，估算 $0.00784124；该结果仅代表这一题。接入与完整验收见 [Pro 说明](swebench-pro-integration.md)。

## 1.5.1 使用变化

正式后台重启到 1.5.1 后，以下修复生效：

- 存储页先显示“正在统计”，完成后自动更新，期间可使用其他页面。“刷新占用”重新统计；容量快照约保留 60 秒，清理前仍实时核对文件。
- 基准入口统一为“基准题目求解”；题集版本和许可在“题集信息”展开查看。断网切题集后点击列表内“重新读取题目”，旧题不会被当作新题集选择。
- 长表单错误显示在操作按钮附近；“定位需要修改的选项”会展开并定位相应字段。
- 失败题的重试按钮直接说明阶段：重新求解会调用模型，仅重新评测不会调用模型。阶段记录显示每次尝试的次数和结果。
- 模型对比的运行条件突出协议、推理强度、价格等差异，完整参数可折叠查看。历史解决率使用最近有效评测的完成时间，不采用最佳成绩；实验首轮口径不变。
- 若后台启动后显示记录“待恢复”，先解除文件占用，再在对应任务重试状态恢复与清理。恢复前阻止新的派发，旧任务不会自动重跑。
- 相同补丁无法确定原对话时显示“来源待确认”，不会拿其他轮求解对话替代。

## 打开与普通任务

1. 双击桌面 **Mini 工作台**，自动启动本地服务并打开浏览器，无需 PowerShell。
2. 在“新建任务 → 编程任务”输入项目路径，或展开“浏览文件夹”。
3. 填写目标，核对模型和运行限制。默认每批命令确认。
4. 点击“开始任务”会调用模型；“先做离线连接检查”不调用付费模型。
5. 检查待执行命令与目录，再批准或拒绝；拒绝可附意见。
6. 在“提交与评测”查看结果，或通过历史记录回看。

对话每页最多 50 条，使用“较早消息／较新消息”回看，或“回到最新”定位结尾。回看时新消息只提示数量；超长单条消息显示节选，完整内容仍在轨迹或事件日志里。

关闭网页不停止任务。停止请点击任务详情“停止任务”，已修改文件不自动回滚。项目目录不是安全沙箱，命令使用当前 Windows 用户权限。

非敏感草稿和项目目录会保留，自动执行和下载授权每次重置。历史里的“复制参数为新任务”只复制参数，不恢复旧代理上下文；新求解会重新调用模型，已有补丁评测则不需要。

## 退出与重启

- **只关闭浏览器：** 后台和任务继续运行。
- **停止任务：** 在任务页点击“停止任务”，等待“停止中／清理中”结束；Python 工作台仍保留。
- **彻底退出：** 点击“退出工作台”，选择“停止任务并退出”或“任务结束后退出”。页面确认服务已退出后即可关闭网页。
- **取消退出：** 点击“保留后台运行”。已经发出的任务停止不会被撤销，也不会自动恢复任务。
- **资源清理失败：** 在任务页重试清理；若 Docker 当前不可用，也可明确选择保留待清理清单并退出 Python，下一次启动再重试。
- **代码更新：** 页面提示有更新时使用“重启服务”；不会静默中断任务。旧版首次升级由桌面入口提示确认，只处理本工作台后台。

如果正在查看的是旧页面，请在后台切换后自行刷新或重新打开入口；不要通过任务管理器结束所有 python.exe／pythonw.exe。

Windows 短暂占用任务记录时，后台会在不足一秒内有限重试保存，不重复调用模型；持续无法写入时保留原文件并显示失败。请先查看任务状态及日志，不要直接重复发起付费求解。

## 设置

### 多模型档案（1.4）

1. 在“模型与设置”点击“添加服务连接”，选择服务模板或填写中转地址并保存。
2. 在连接下方独立加密保存密钥。可以主动“获取模型列表”，也可以按服务商说明直接填写模型 ID；获取列表不代表工具调用已验证。
3. 添加模型档案，选择连接、Chat Completions 或 Responses 协议、生成参数和运行限制。使用自定义别名时填写该服务的每百万 token 价格；未知费用不能填零，免费需明确选择。
4. 可以保存多个模型并选择网页默认档案；新建任务、实例库批次分别支持本次模型选择。原配置及原命令行入口不随网页切换覆盖。
5. “验证工具调用”先显示范围，勾选确认后最多调用两次、每次最多 256 输出 token，费用检查阈值 $0.05。不会执行返回的工具命令。网络结果不明时不自动重试，请先核对服务商调用记录。

验证结果与时间会显示在模型列表，原配置也支持。未勾选授权和调用失败会在验证按钮附近提示。完成后点击“重新验证”重新预览并勾选授权；连接中断或页面刷新时，使用“查询上次结果”，不会重复调用模型。后台重启遗留的验证显示“未完成验证”，请先核对服务商记录。预览显示实际模型 ID 与协议；内部 openai/ 前缀不额外发给服务商。

若始终查不到记录，面板会提供“结束本次等待”。阅读说明并勾选确认后，后台会阻止迟到的原提交，再允许重新预览；这不能取消服务商已经收到的请求。后台仍在验证时不能结束等待。若提示结果保存失败，请保持后台开启、解除文件占用或检查磁盘，再查询结果；查询只重试保存，不重新调用模型。Responses 推理强度会按该协议发送，预览展示实际生成参数。

协议、模型、参数或密钥变化后，旧验证不代表当前配置可用。不同连接可用同一个模型 ID，价格和凭据分别保存。停用档案保留历史；正在运行的任务使用自己的冻结参数，不热切换密钥。模型测试期间要等测试结束再退出或重启。

下列原配置操作仍适用于“原配置与兼容设置”区域：

“模型与设置”可修改模型、API Base、接口类型、最大步数、费用估算阈值和超时。保存只影响新任务，不调用模型。已有密钥不显示；替换时使用独立密钥表单，由 Windows 加密保存。不要把密钥放入任务、YAML 或命令参数。

密钥状态只证明本机可解密，不等于服务商认证通过。保存失败会保留输入；保存密钥不覆盖同页的其他未保存设置。配置损坏时仍可进入设置，恢复备份或明确“备份并重建配置”。

其他窗口修改配置后，会出现冲突面板。逐项选择最新保存值或自己的编辑，点击“合并到最新版本”，检查后再保存。未冲突字段自动合并；这一步不会立即覆盖服务器配置。

API Base 使用服务商提供的完整地址，不附密钥。费用估算不等于账单；限制在请求之间检查，单次请求可能超出阈值。实际兼容性需要获准发起真实请求后验证。

网页任务的默认调用保护随本次步数设置调整，不再被隐藏的固定 45 次默认值截断；若用户在环境或 .env 显式设置 MSWEA_GLOBAL_CALL_LIMIT，仍遵守该限制，并在设置页提示。

## SWE-bench

### SWE-rebench 经典榜单（1.5）

在实例库或新任务的题集下拉选择 **SWE-rebench 经典榜单**。本次固定 860 题版本 `34d5a588`，与 Verified/Lite 分开保存。目录同步约读取 4.86 MB 数据，只保存公开说明；获取未缓存单题也会读取这个小数据文件并仅保存所选题目。镜像另行勾选授权，Docker 未运行时显示“无法检查”。

操作仍为选题 → 检查批次 → 确认下载与预算 → 求解／评测。`_interface` 题号可直接从列表选择，必需接口会附在说明中。切换题集会清除不适用的题号、补丁和预览，撤销下载及自动执行授权；每页默认仍是 8 题。

评测中心先筛选该题集再比较模型，不把 SWE-rebench 与原 SWE-bench 的解决率合并排名。外部预测需要明确 `dataset=rebench-34d5a588` 或对应 `case_key`；优先使用本工作台同题求解产生的补丁。

没有增加虚拟环境或安装包，官方评测源码独立加载。已获准下载并验证 Click-3239 的官方镜像，GPT-5.5 真实单题求解与评测通过（修复 4/4、回归 694/694，估算 $0.232104）；其他题目仍按需授权下载和求解。评测启动失败后，修复原因可只重试当前评测阶段，保留旧记录和原补丁，不需要重新调用模型。详细来源与边界见 [接入说明](swe-rebench-integration.md)。

### 实例库与多题队列

1. 点击左侧“实例库”。已同步的目录可直接搜索和筛选；没有目录时点击“同步题目目录”，只获取题目信息，不下载镜像。
2. 按题号、仓库或关键词找题，查看题目缓存、运行环境、已有补丁和最近评测结果。Docker 无法检查时显示“无法检查”，不要把它当作尚未下载。
3. 勾选题目，可跨页选择，最多 50 题；点击“配置所选题目”进入批次选项。
   “每页显示”默认 8 题，可选 8／16／25／50。切换后回到首页，已勾选题目保留；刷新仍使用本浏览器上次选择。
4. 选择缓存题目、下载环境、求解或评测。按需要分别授权题目资料和镜像下载；只有求解调用模型。自动评测只使用本次成功生成的补丁。
5. 点击“检查所选题目”。已有补丁只有一个匹配选项时自动选择，多份补丁需选定；也可填写本题补丁路径。改动补丁选择后重新检查。
6. 核对题目、操作、缺失资源和费用，再勾选确认并开始。默认仍需到子任务页面批准命令；只有明确勾选本批自动执行才跳过逐批命令确认。

队列一次只运行一个步骤。执行异常会暂停；正常评测未通过保留结果并继续。“当前题结束后暂停”包括本题已勾选的自动评测；“停止当前题并暂停”会停止当前步骤并等待清理。失败或中断题需明确重新尝试或跳过，重试保留旧记录。

后台重启后队列保留并暂停，不自动重新调用模型。“继续未开始任务”前需处理失败／中断题；配置或密钥变化时先核对当前设置。结束批次会停止本批当前任务并取消剩余条目，已有结果保留。

本批预算默认等于当前单题费用上限，同时保留每题步数和费用限制；达到估算上限后不再请求下一次模型回复，单次调用仍可能超限。未知计价或中断请求的费用无法确认时停止后续求解；请核对服务商账单并结束批次，再重新安排，不能把本机估算当成硬性账单上限。

目录、队列状态和补丁快照独立保存；未完成队列引用的子任务受保护，不会列为可清理记录。镜像标称大小不是新增磁盘占用；本功能不自动下载全部镜像，也不自动删除旧镜像。

任务结束但状态写入或清理失败时，进入对应任务点击“重试状态恢复与资源清理”；状态恢复也可能没有待删容器。恢复成功后队列接收原结果，原求解已提交的补丁可以继续评测，无需重新求解。Docker 命令超时会停止当前求解并清理所属容器。修改预算、模型、题目或授权后需要重新检查批次，旧预览不能继续提交。

### 原单题入口

**新求解：** 确保 Docker Desktop 的 Linux 引擎正常 → 选择单题与数据集 → 搜索并选择题目 → 点击加载题目 → 在可取消的加载任务完成页选择“使用本题求解” → 核对模型和下载授权后开始。提交后可进入已有补丁评测。

“选择题目”支持输入题号、仓库名或题目关键词，点击候选项后自动填入完整 ID；也可使用方向键和回车选择，Escape 收起，或直接粘贴完整题号。输入为空时展开前 8 项，搜索匹配较多时继续输入缩小范围。列表来自当前数据集的本机目录，未同步时可从下方入口前往实例库同步，不会自动下载镜像或启动模型。求解和已有补丁评测共用这一入口；重新选题后重新匹配补丁，并重置执行／下载授权。

**已有补丁：** 选择“评测已有补丁” → 填题号并核对本机缓存 → 选择匹配补丁 → 开始评测。未缓存时才需要“加载题目”。刷新后会重新检查缓存，不必反复创建加载任务。不会重新调用模型。

同补丁、同来源模型的预测与轨迹合并显示；不同模型保留独立选项。只有一个匹配选项时才推荐。推荐不代表评测通过；无题号的未知轨迹不会自动关联。手动路径填写后先点击“检查这个文件”。

评测默认显示阶段日志和最近日志时间。测试正文可能在结束后才写入，不能据“没有新文字”判断卡死。单题测试超时为 1800 秒，准备和清理另计，与设置页的模型／命令超时分开。

“补丁生成对话”显示与本次输入补丁及来源模型一致的历史轨迹，不是评测产生的新回复；找不到匹配或消息超限时会明确说明。

优先复用缓存。允许下载需勾选；新镜像可能占用数 GB。每次评测生成独立运行编号，不覆盖旧结果。轨迹缺少 instance_id 时由用户确认其归属；有明确编号时进行一致性校验。

“已完成”只代表流程结束。结果分为通过、测试未通过、疑似环境失败、原因不明确、评测异常或未完成。环境和不明确分类不改变原 resolved 数值，也不能自动认定补丁正确或错误。

“题目代码初始化失败”发生在模型请求之前：打开“命令与日志”查看初始化退出码、Git 输出和异常。1.3.2 起保留这些信息，旧记录没有保存的原因无法补回。队列仍暂停，需要在实例库对失败题点击“重新尝试”，再明确继续；初始化成功后会进入模型求解并可能产生费用，不会由诊断过程自动代为继续。

## 历史、结果和空间

### 一体化评测与模型对比（1.4）

模型对比默认优先选择具有共同题目的不同模型；展开“选择对比模型”可搜索并勾选。每个实际模型只显示一行，历史运行条件在该行下拉选择；切换后点击“应用选择”更新。原配置显示实际模型名，不再出现多个同名入口。导出采用已显示的比较条件。对比矩阵直接显示修复与回归测试数量，点击结果在同页展开各模型明细；“统计口径与执行条件”保留参数差异。手机窗口按题目逐个排列各模型结果。

费用未知的批次不能继续，请核对服务商账单后结束批次。Docker 本机启动出现致命退出码时，工作台会结束求解并保留原因，不再让模型反复尝试；这类问题不代表补丁测试失败。


- 新 SWE-bench 求解默认勾选“成功提交后自动评测”，可关闭；仅本次成功且非空的提交会进入评测。资料和镜像下载仍需另行勾选。任务页展示准备、求解、提交、评测和结果，阶段入口可回看日志。
- “评测中心 → 结果总览”查看题目解决率及样本数；单题分别查看修复测试、回归测试。整体测试通过 95.2% 仍可能未解决，最终以官方 resolved 为准。
- “模型对比”可对齐历史共同题集，缺测、异常和被排除的题目明确显示。历史不同题集的百分比不能直接排名；少量自选题不是全集成绩。
- “建立同题实验”从实例库带入已选题目，选择最多五个模型，模型乘题目不超过五十。确认统一限制、执行顺序和总预算。实验与原队列共用执行槽，逐题逐模型执行；默认成功提交后自动评测。
- 实验主成绩固定采用首轮，重新求解的重试另列；同一补丁重新评测不增加题目数。执行异常暂停，普通测试不通过继续。重启后需手动恢复；运行条件变更应另建实验，只有密钥变更可再次确认继续。
- 已完成实验可对具体条目选择“重新求解（保留首轮）”。确认后生成新的尝试并先暂停，核对剩余总预算后再点击继续；预算不会自动增加，耗尽时另建实验。失败/中断条目的“重试当前阶段”只重试当前失败步骤。
- CSV/JSON 导出仅含脱敏结果、参数条件和统计口径，不含原对话或密钥。缺失费用和耗时显示未知，已知费用只是估算。

原接口没有传 auto_evaluate 时仍保持旧行为，旧队列不会因升级自动获得新授权。结果来源不明确的旧记录保留为“仅评测记录”，不虚构对应求解、费用或耗时。

已完成或取消的实验也会保护首轮及其后续重评的任务目录，以保持首轮成绩可回看；明确产生的重试记录仍可按原流程清理。已知来源任务缺失时保持来源未知，不会自动借用另一个同名模型或相同补丁的结果。

历史支持搜索、分页和归档。归档只影响列表显示，不移动原文件。提交页仅显示已实际生成的产物；屏幕日志限制长度，完整事件日志可以下载。

“运行期间变化的文件”来自独立前后指纹，不能区分同时进行的人工修改。新建、修改、删除的安全 UTF-8 文本可以展开运行前后内容预览，非 Git 项目也可使用；不会暂存文件或改变 Git 索引。指纹限单文件 2 MB；内容预览快照限单文件 200 KB、合计 2 MB，差异输出合计最多 2 MB，页面预览前 30 个文件、每项最多 4000 字符。超限、二进制、旧快照和隐私限制会说明原因，不生成空差异下载。含疑似凭据的下载或参数复制仍会被阻止。

存储页先显示占用，再列出可清理的已结束任务与旧配置备份。必须先预览精确路径和大小、勾选确认，再删除；预览后文件变化会拒绝操作。原配置、密钥、原有评测、HF 缓存和 Docker 镜像不在自动清理范围，最近可用配置备份始终保留。

测试与审查目录统一计入“开发测试与审查资料”，其他命名计入“其他工作台资料”，不再漏统计。这些资料仅统计，不自动删除；需要清理时先核实具体路径、是否有活动实例和应保留的验收证据。

## 故障处理

| 现象 | 处理 |
| --- | --- |
| 会话失效 | 重新双击桌面快捷方式，不分享 service.json |
| 连接失败 | 点击“重新连接”；未确认的提交先核对原请求，避免重复运行。后台可能仍在执行 |
| 配置冲突 | 重新进入设置，读取新值后再保存 |
| Docker 未就绪 | 在 Docker Desktop 检查引擎；下载镜像不能解决引擎启动故障 |
| 镜像缺失 | 确认磁盘空间后允许下载；本工具不自动清理镜像 |
| LF 修复缺失 | 使用下方已有修复脚本，不重装整个环境 |
| 长时间无输出 | 查看状态与超时；需要时仅停止本任务 |
| 补丁提交但未通过 | 查看正式报告和日志，区分补丁错误与基础设施错误 |

Docker 状态和正式评测的最近验证见 current-state.md；早期启动故障仅为历史记录。不要按旧故障描述删除 docker_data.vhdx、镜像或容器数据。

## 维护命令

下面均在 **PowerShell** 执行，不粘贴到 mini 任务框：

```powershell
Set-Location 'F:\mini-swe-agent'
$py = Join-Path $PWD '.venv\Scripts\python.exe'
& $py -m pip check
& $py -m pytest -c local_setup/webui/tests/pytest.ini local_setup/webui/tests -q
```

先检查现有环境与依赖再安装。requirements.txt 是服务依赖，requirements-test.txt 添加测试依赖；不要直接安装整个 dev 套件。

必要时检查／恢复已有 Windows 换行修复：

```powershell
Set-Location 'F:\mini-swe-agent'
& '.\.venv\Scripts\python.exe' 'local_setup\fix_swebench_windows_newlines.py'
```

原命令行备用入口：

```powershell
Set-Location '你的目标项目目录'
& 'F:\mini-swe-agent\mini.cmd'
```

不打开浏览器的维护启动：

```powershell
Set-Location 'F:\mini-swe-agent'
& '.\.venv\Scripts\python.exe' 'local_setup\webui\launch.py' --no-browser
```

内部变量：MINI_WEB_STATE 指定独立状态目录，MINI_WEB_CONFIG_ROOT 指定隔离配置根，MINI_WEB_PORT 指定端口。MINI_WEB_TESTING=1 仅用于隔离实例的受控诊断场景，不在用户默认实例启用。MINI_WEB_NONCE 由启动器管理，不公开或放入命令参数。浏览器 QA 可用 MINI_PLAYWRIGHT_MODULE 指向已有 Playwright，不重复安装浏览器。完整隔离验证命令见修复清单。
